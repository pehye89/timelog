# TimeLog

업무 시간을 타이머로 기록하고, 운영 단위로 관리하고, 주간 보고서를 만드는 개인용 웹 앱입니다.
빌드 과정 없는 정적 사이트라 GitHub Pages 등 정적 호스팅에 폴더 그대로 올리면 바로 동작합니다.

## 구조

```
index.html          진입점, 모든 탭/모달 마크업
css/style.css        전체 스타일 (디자인 토큰 기반)
js/
  utils.js           공용 헬퍼, 불릿 에디터
  state.js            전역 상태
  storage.js          localStorage 입출력
  settings.js          설정 모달 로직
  backup.js            Google Drive 온라인 백업
  tracker.js            타이머 탭
  history.js           타임로그 목록/수정
  timeline.js          그리드 타임라인
  management.js         운영 관리 탭
  weekly.js              주간보고 탭
  modals.js               모달 공통 열기/닫기
  app.js                   초기화, 이벤트 바인딩
```

데이터는 브라우저 `localStorage`에 저장됩니다 (서버 없음). 다른 기기와 동기화하려면 설정 상단의
"내보내기 · 백업" 모달에서 파일 내보내기/가져오기 또는 Google Drive 온라인 백업을 사용하세요.

## 버전 관리

버전은 `yymmdd.nn` 형식입니다 (예: `260827.01` = 2026년 8월 27일의 첫 번째 배포).
- 앱 안에서: 설정(⚙️) 모달 맨 아래 중앙에 옅게 표시됩니다.
- 코드 캐시 무효화: `index.html`의 모든 `css/js` 링크에 `?v=yymmdd.nn` 쿼리스트링으로 붙어 있어,
  배포할 때마다 브라우저가 옛 캐시 대신 새 파일을 받아오도록 강제합니다.

**이 저장소를 수정할 때마다, 아래 변경 이력에 새 버전 항목을 추가합니다.** 같은 날 여러 번 수정하면
`.02`, `.03`처럼 일련번호만 올라가고, 날짜가 바뀌면 `.01`부터 다시 시작합니다.
