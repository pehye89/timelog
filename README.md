# TimeLog

업무 시간을 타이머로 기록하고, 운영 단위로 관리하고, 주간 보고서를 만드는 개인용 웹 앱입니다.
빌드 과정 없는 정적 사이트라 GitHub Pages 등 정적 호스팅에 폴더 그대로 올리면 바로 동작합니다.

## 구조

```
index.html          진입점, 모든 탭/모달 마크업
css/style.css        전체 스타일 (디자인 토큰 기반)
js/
  utils.js           공용 헬퍼, 불릿 에디터
  state.js            전역 상태
  storage.js          localStorage 입출력
  settings.js          설정 모달 로직
  backup.js            Google Drive 온라인 백업
  tracker.js            타이머 탭
  history.js           타임로그 목록/수정
  timeline.js          그리드 타임라인
  management.js         운영 관리 탭
  weekly.js              주간보고 탭
  modals.js               모달 공통 열기/닫기
  app.js                   초기화, 이벤트 바인딩
```

데이터는 브라우저 `localStorage`에 저장됩니다 (서버 없음). 다른 기기와 동기화하려면 설정 상단의
"내보내기 · 백업" 모달에서 파일 내보내기/가져오기 또는 Google Drive 온라인 백업을 사용하세요.

## 버전 관리

버전은 `yymmdd.nn` 형식입니다 (예: `260827.01` = 2026년 8월 27일의 첫 번째 배포).
- 앱 안에서: 설정(⚙️) 모달 맨 아래 중앙에 옅게 표시됩니다.
- 코드 캐시 무효화: `index.html`의 모든 `css/js` 링크에 `?v=yymmdd.nn` 쿼리스트링으로 붙어 있어,
  배포할 때마다 브라우저가 옛 캐시 대신 새 파일을 받아오도록 강제합니다.

**이 저장소를 수정할 때마다, 아래 변경 이력에 새 버전 항목을 추가합니다.** 같은 날 여러 번 수정하면
`.02`, `.03`처럼 일련번호만 올라가고, 날짜가 바뀌면 `.01`부터 다시 시작합니다.

## 변경 이력 (Changelog)

### 260828.03
- "완료" 배지 위치를 운영명 뒤 → **앞**으로 이동
- 운영목록 정렬 규칙 확정: 완료된 운영은 항상 맨 아래로 밀리고, 완료 항목끼리는 **가장 최근에 완료된 것이 위로** (완료가 아닌 항목은 기존처럼 운영번호 순)
- 타임라인 행 순서: 사용자가 드래그로 순서를 바꾸기 전까지는 매 렌더링마다 실행 시각 기준으로 계속 다시 정렬됨 (기존엔 한 번 정해진 순서가 그대로 굳어서, 실행 시각이 바뀌어도 반영되지 않던 문제가 있었음). 드래그로 한 번이라도 수동 정렬하면 그 날짜에 한해 그 순서가 유지되고, 날짜를 이동하면 다시 실행순으로 초기화됨
- 운영목록의 완료 항목은 **최근 30일 이내 완료된 것만** 표시 (더 오래된 완료 건은 운영 관리 탭에서 확인)
- 운영목록이 12개를 넘으면 운영 관리 탭과 동일한 방식의 페이지네이션 적용
- 버그 수정: "완료 포함" 토글이 꺼져 있으면, 완료된 지 오래된 운영은 그날 실제로 기록한 시간이 있어도 타임라인 그리드에서 통째로 안 보이던 문제 수정 — 이제 토글 상태와 무관하게 **그날 실제로 기록된 운영은 항상 타임라인에 표시**됨 (삭제된 운영은 예외에서 제외)

### 260828.02
- 완료된 운영도 타이머로 기록을 계속 추가할 수 있도록 개선
  - 타이머 탭 운영 목록에 "완료 포함" 토글 추가 (기본 꺼짐) — 켜면 완료된 운영도 목록에 나타나고, 재생 버튼으로 바로 기록 가능
  - 같은 토글로 타임라인 그리드에도 완료된 운영의 행이 함께 표시됨
- 운영 목록·타임라인의 정렬 우선순위를 "완료 여부"에서 "실행 여부"로 변경 — 오늘 먼저 기록을 시작한 운영이 위로, 아직 기록이 없는 운영은 아래로 (진행중/완료 상태와 무관)
- UI 개선: "완료 포함", "미실행 숨기기" 체크박스를 앱 전반에서 쓰는 알약형 토글 칩 버튼으로 통일
- 버그 수정: 운영명이 길어 말줄임(...) 처리될 때 옆의 "완료" 배지까지 함께 잘려나가던 문제 수정 (제목만 줄임 처리, 배지는 항상 온전히 표시)
- 버그 수정: "미실행 숨기기"가 켜진 상태에서 그날 기록이 없던 운영을 처음 재생하면, 실행 중임에도 타임라인에 바로 나타나지 않던 문제 수정 (`startTimer`/`checkActiveTimer`에서 셀 클래스만 토글하던 것을 전체 재렌더링으로 교체)
